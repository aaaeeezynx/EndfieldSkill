### Fallback 策略
當角色圖片無法載入時，使用 SVG 佔位符顯示：
- 角色名稱首字
- 職業圖示（近卫/術師/先鋒等）
- 稀有度星級
- 明確標註「立繪缺失」

### 技術實作
- 圖片使用 `loading="lazy"` 延遲載入
- 提供 `alt` 屬性用於無障礙存取
- 使用 `object-fit: cover` 保持圖片比例
- 錯誤處理：`@error` 事件觸發 fallback 顯示

### 自製資產
所有背景 SVG、圖示、佔位符均為專案自行設計，不使用官方資產。

### 介面裝飾（2026-10-23）
- CSS 網格、掃描光帶、切角、光暈、狀態點與角色缺圖字母 fallback 均由專案以 CSS/文字即時繪製，沒有新增二進位或遠端素材。
