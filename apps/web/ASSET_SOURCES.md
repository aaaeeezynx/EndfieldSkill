### Fallback 策略
當角色圖片無法載入時，使用 SVG 佔位符顯示：
- 角色名稱首字
- 職業圖示（近衛／術師／先鋒等）
- 稀有度星級
- 明確標註「立繪缺失」

### 技術實作
- 圖片使用 `loading="lazy"` 延遲載入
- 提供 `alt` 屬性用於無障礙存取
- 使用 `object-fit: cover` 保持圖片比例
- 錯誤處理：`@error` 事件觸發 fallback 顯示

## 設計系統

### 視覺語言來源
- **參考網站**: https://endfield.gryphline.com/zh-tw
- **設計風格**: 工業科幻、白底編輯風、幾何切角、硬邊面板與黑色 footer
- **字體**: Rajdhani (標題、編號、代碼)、IBM Plex Sans (正文)、IBM Plex Mono (等寬)
- **配色**:
  - 背景: #ffffff、#f0f0f0
  - 文字: #191919、#595959
  - 強調色塊: #fffa00（黃）、#2257d6（藍）、#ff6b00（橘）
  - 邊框: #d9d9d9、#191919
- **裝備稀有度色框（五級）**: 灰、綠、藍、紫、金

### 自製資產
所有背景 SVG、圖示、佔位符均為專案自行設計，不使用官方資產。

### 介面裝飾（2026-10-23）
- CSS 網格、掃描光帶、切角、光暈、狀態點與角色缺圖字母 fallback 均由專案以 CSS/文字即時繪製，沒有新增二進位或遠端素材。
- 角色立繪在編成、摘要與裝備卡統一使用本地 `public/assets/character_portraits/`，映射與原始官方 CDN URL 見上表；不把資料集內圖片 URL 當作執行時資產來源。
- 裝備圖統一使用本地 `public/assets/equipment/`，並依稀有度套用五級色框；18 筆缺圖以 `EquipmentArtwork.vue` 的 fallback 渲染。
